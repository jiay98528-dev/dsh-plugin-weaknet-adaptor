# Security Policy / 安全策略

## Supported versions / 支持版本

Only the latest npm release receives security fixes.

## Reporting a vulnerability / 报告漏洞

Please **do not** open a public issue for a suspected security vulnerability.

Report it privately to the repository owner through GitHub, including:

- affected plugin and DSH versions;
- reproduction steps or a minimal proof of concept;
- expected impact;
- any suggested mitigation.

We will acknowledge reports as soon as possible and coordinate a fix before public disclosure.
